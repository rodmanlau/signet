# Signet

Signet issues proofs. A world checks a proof locally and does not call Signet to ask who someone is.

The packages are `@signet/proof`, `@signet/server`, and `@signet/client`. Only `@signet/proof` is published. Valar depends on that published version and does not depend on the server or the client.

Operators follow [Run Signet](docs/login.md).
