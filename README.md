# Signet

Signet issues proofs. A world checks a proof locally and does not call Signet to ask who someone is.

The packages are `@agenticage/proof`, `@agenticage/server`, and `@agenticage/client`. Only `@agenticage/proof` is published. Valar depends on that published version and does not depend on the server or the client.

Operators follow [Run Signet](docs/login.md).
